# HoI4向け艦船設計支援ツール群

このリポジトリは、Paradox社のゲーム「Hearts of Iron IV」(HoI4)のMOD開発、特に海軍関連のデータ作成を支援するための一連のPythonツール群です。GUIベースの艦船設計ツールや、データ処理スクリプトなどが含まれています。

## 主なツール

このリポジトリには、以下の主要なツールが含まれています。各ツールは個別のPythonスクリプトとして実行できます。

### RtW-Like Ship Designer (`RtW_Like_designer.py`)

`Rule the Waves`ライクな、詳細な艦船設計を行うためのグラフィカルなメインツールです。船体、装甲、兵装、機関などを細かく設定し、艦船の性能をシミュレートしながら設計を進めることができます。設計した艦船のグラフィックを視覚的に確認することも可能です。

**実行方法:**
```bash
python RtW_Like_designer.py
```

### Light Ship Editor (`Light_ship_editor.py`)

よりシンプルな、フォームベースの艦船データエディタです。グラフィカルな表示はありませんが、艦船の基本的なステータスや装備を素早く入力し、ゲーム用のデータとしてエクスポートすることを目的としています。

**実行方法:**
```bash
python Light_ship_editor.py
```

### Fleet Designer (`fleet_designer.py`)

国別に編成された艦隊、タスクフォース、そして所属する艦船を一覧で表示・管理するためのツールです。CSV形式のデータベースを読み込み、艦隊の構成を確認したり、特定の艦船の設計詳細をドリルダウンして表示したりすることができます。

**実行方法:**
```bash
python fleet_designer.py
```

### Ship Hull Designer (`ship_hull_designer.py`)

艦体データが記述されたCSVファイルを読み込み、ゲーム内で使用されるステータス（耐久値、コスト、視認性など）を自動計算して、MOD用の`.txt`ファイルとして出力するコマンドラインツールです。

**実行方法:**
```bash
python ship_hull_designer.py
```

## ディレクトリ構造

プロジェクトは以下の様に構成されています。

- **ルートディレクトリ**: 主要なツールの実行スクリプトが配置されています。
- `utils/`:
  - `actions/`: GUIのボタン操作など、特定のアクションに関連するスクリプト。
  - `coefficient/`: コストやHPなどの係数計算に関連するスクリプト。
  - `database/`: 国旗(FLAGS)、史実艦データ(REAL_SHIP_DATA)、艦船設計データ(design)など、ツールが利用する各種データが格納されています。
  - `graphic/`: GUIのグラフィック描画に関連するスクリプト。
  - `tools/`: 各種ユーティリティスクリプト。
  - `converter.py`: 各種計算処理のコアとなる変換ロジック。

## 依存関係

このツール群を実行するには、以下のPythonライブラリが必要です。`pip`を使用してインストールしてください。

```bash
pip install Pillow pdx-tools
```

- **Pillow**: GUIでの画像表示や処理に使用します。
- **pdx-tools**: Paradox社のゲームファイル（`.txt`など）を扱うためのツールと思われます。
